Critical findings affect the Vitest/tinypool test-tooling chain; high findings also
include production watcher dependencies through chokidar. Several offered fixes
require major dependency upgrades. Findings have not been remediated or dismissed
as unreachable. Dependency remediation and compatibility validation are required
before publishing; this release remains a draft.

No npm packages, binary bundles, private workspaces, or new execution/session
artifacts are attached. The release branch contains the version changes, release
notes, input-review documentation clarification, and release test updates only.
